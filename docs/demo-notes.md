# Alexandria demo — presenter notes

**Open:** Alexandria, unlocked demo profile; Cloud at <http://127.0.0.1:8787>.
**Directory:** `http://127.0.0.1:8787` in Alexandria → Settings → Directories.
Unlocking runs the bundled seeds. Use JavaScript and Big-O, which have question banks.

## 1. Learner first

1. **Alexandria → Skills → JavaScript → assessment.** Answer and submit.
   Say: “The assessment runs on this device.”
2. **Show Sentinel Dev:** click its assessment button or press **⌘⇧S**.
   Say: “These are live local integrity signals.”
3. **Open the earned credential.** Point out its ID, score, skill, issuer, and integrity summary.
4. **My profile → Let employers find you:** choose JavaScript, review and save consent.
   **Settings → Directories:** publish to Local demo.
5. **Cloud → Talent:** JavaScript, **Remember**, **0 issuer clusters**. Add the person to candidates.
6. **Candidate → Invite to assess or share:** uncheck “Require a new assessment.”
   **Alexandria → Directories:** refresh requests, choose credential, preview, share.
   **Cloud run:** refresh and show the matching credential ID and verification result.

## 2. Organization first

1. On the same Cloud candidate, request **Big-O Analysis** with **Require a new assessment** checked.
2. In Alexandria → Directories, refresh and **Take requested assessment**.
3. Show **⌘⇧S**, complete the assessment, then preview and share its new credential.
4. Refresh the Cloud run; return to the candidate to show the recorded assessment.
   Say: “This credential answers this specific invitation.”

## Three points to say clearly

- “The learner chooses what gets published and what gets shared privately.”
- “A perfect factual quiz earns **Remember**, not a higher Bloom level.”
- “This is learner-issued evidence: a valid signature adds **no independent issuer corroboration**.”

**If needed:** use the passive Sentinel button during an assessment. Full **Diagnostics → Sentinel live view** is for a separate camera-preview demonstration; exit diagnostics before assessing. Avoid reloading an open attempt—normal cooldowns apply. If sharing fails, retry the same preview promptly and refresh Cloud.
